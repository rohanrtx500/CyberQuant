## 📌 Project Overview
CyberQuant AI is an AI-powered platform designed for continuous cyber risk intelligence and investment optimization. It ingests telemetry data from enterprise security tools (SIEM, EDR, IAM, and vulnerability scanners) and maps them to business assets to quantify cyber risk into monetary exposure and prioritize security remediation.

## 🚀 Tech Stack
- **Frontend:** Next.js / React, TypeScript, Tailwind CSS
- **Backend:** Python, FastAPI, PostgreSQL, Redis
- **AI / ML:** Risk modeling & quantification algorithms
